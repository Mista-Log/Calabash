## 🎯 **Lecturer Demo Flow (3 minutes)**

### **Minute 0-1: Dashboard Overview**
```
1. Login as lecturer
2. Show Quick Dashboard
   - Point out stats cards
   - Highlight quick actions
   - Show recent courses
```

### **Minute 1-2: Upload Material**
```
1. Click "Quick Upload"
2. Fill material details
   - Title: "Lecture 5 - Data Structures"
   - Course: "CSC 201"
   - Type: Video
   - Source: YouTube URL
3. Show review step
4. Publish
```

### **Minute 2-3: Manage Materials**
```
1. Go to a course
2. Open "Digital Library" tab
3. Show material list
4. Select multiple materials
5. Bulk make private
6. Edit one material
7. Show delete confirmation
```

### **Bonus (if time): Analytics**
```
1. Click "Analytics"
2. Show engagement charts
3. Point out top resource
4. Export to CSV
```
